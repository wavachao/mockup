## 本次修改

- 快速添加改用标准底部弹窗，正确处理系统返回、键盘和无障碍焦点；展开详细编辑时保留标题、日期、时长等输入。
- 编辑草稿支持状态恢复；修正时间滚轮初始偏移和旧回调覆盖新值的问题，调整开始时间时保持时长。
- 增加可编辑备注、日期选择、具名分类、跨天说明；拦截空标题，删除与放弃修改均有确认。
- 修正时间轴重叠分列、右侧越界、嵌套安排误报空档；窗口覆盖当天实际安排，避免首个安排前出现大量空白。跨夜安排在当天时间轴截到午夜，详情保留原始完整时长。每小时高度增至 96dp，短时段使用紧凑卡片。
- 修正图标描边重复缩放并规范圆弧路径参数，改用 Compose 的 SVG 解析器；补充首页空状态。页面按导航栏实际高度预留空间，底部按钮随之定位，导航图标使用统一尺寸。
- 编辑保留完成状态和创建时间；详情直接订阅数据库变化，通知在应用已运行时也能打开对应日程。
- 限定页面订阅仅在日期范围变化时重建，避免状态更新反复触发数据库查询；新增保存失败反馈及重复提交防护。
- “不提醒”和已完成日程不再创建闹钟；恢复“开始时提醒”的启动重建；创建重复日程时为已生成实例设置提醒，重复范围从用户选择的日期计算。
- 通知权限改在首次保存需要提醒的日程后申请，拒绝授权时提示且保留已保存数据。
- “我的”显示真实总数、通知权限入口和本地数据说明，移除开发调色板；回到今天会重置所选日期。
- 按 Android API 版本拆分主题属性，修复旧系统兼容性检查错误；Lint 错误会阻止构建。版本号为 1.0.1（versionCode 2）。

## 自动测试范围

JVM 测试涵盖原有数据转换、时间格式、统计、时间轴，以及本次增加的编辑元数据保留、移动开始时间、跨夜和嵌套空档回归。

设备测试实际运行 Compose 界面和 Room 数据库：

1. 快速添加的系统返回操作。
2. 非今天日期创建，展开详细编辑后保存，重建 Activity 后读取记录。
3. 运行中通知打开详情，完成状态即时更新，再编辑仍保留完成状态。
4. 删除确认与取消。
5. 连续操作小时与分钟滚轮仍保持时长。
6. 标题和备注状态恢复。
7. 编辑器初始时间和传入草稿不被自动修改。
8. 空标题不能保存。
9. 真实 Room 新建、完成、编辑、观察与删除。
10. 从三个月后的日期开始生成 28 天重复安排。
11. 重叠日程在实际渲染中分列且不超出屏幕。
12. 铃铛图标圆弧在标准视口内正确解析。
