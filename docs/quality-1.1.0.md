# 1.1.0 日程功能重做与验收

- 首页按日期展示未来日程，可搜索标题/备注，切换历史和全部；查询不再限于最近 28 天。
- 新建页支持具体时间、全天事项及跨日期安排；开始/结束日期独立选择，24 小时制直接输入小时和分钟，结束早于开始会阻止保存。
- 从日历选日期后新建，会带入选定日期。详情显示真实日期、时间和备注，支持编辑、完成、删除确认。
- 新增按钮独立预留空间；编辑内容滚动，保存按钮常驻；深色文字对比度和小屏幕日历标题已调整。
- Room 1→2 迁移新增全天字段，保留原有记录；全天提醒以当天上午 9 点为基准，启动时恢复远期提醒。

## 验证结果

- 54 项 JVM 测试通过，0 失败，覆盖跨日、全天结束日期、无效结束时间和编辑数据保留。
- Android 15 / API 35 模拟器：14 项 instrumentation 测试全部通过，最终日志 `redesign-instrumentation-final.log`。
- 设备测试包括精确输入 14:37 并保存、全天保存、草稿恢复、删除确认、完成后编辑、一年后安排搜索、真实 SQLite 数据库升级保留旧记录、两年后的全天事项查询。
- 手动安装最终 release APK，旧版 Release Review / Acceptance notes 记录仍保留。
- 手动检查普通屏幕，以及 320dp 宽、字体 1.3 倍下的日历、编辑、全天和时间输入弹窗；键盘打开时确定按钮仍可见。
- APK v2 签名和 zipalign 校验通过。签名沿用现有本地测试密钥。
- 本轮 Lint 检查 0 错误；最后的时间输入调整通过重新编译及设备测试验证。

测试范围为模拟器，未连接实体手机；未验证各厂商后台省电策略下的通知到达时间。
