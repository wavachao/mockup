# 1.2.0 操作、视觉与统计验收

## 使用上的改进

- 新建日期可直接点今天、明天或一周后；开始和结束时间并排显示，常用时间点选即确定，也保留精确输入。
- 同日安排不再重复要求结束日期；需要跨天时展开。全天事项与具体时间共用一套编辑流程。
- 记住上次的分类和具体时间日程的提醒选项；保存后返回列表，可从提示点“查看”。
- 列表支持完成、撤销完成、编辑、移到明天和选择日期改期；改期保留时长和备注。
- 过期但未完成的事项保留在待办中；搜索支持一键清空。四个首页筛选项在小屏幕上并排显示，无需横向寻找。
- 日历可收起到一周，选定日期旁可直接新建。
- 修复实测发现的完成提示遮挡后续保存操作：提示避开操作区，进入编辑时收起旧提示。

## 视觉

采用浅色暖灰底、白色卡片和低饱和绿色，统一字体层级、圆角、按钮、空状态及分类色标。重画桌面日历勾选图标，更新日程、设置等导航图标，并统一描边。详情和设置页一起调整。

## 统计

独立统计入口，按周/月及前后区间查看：总安排数量、已完成数量、完成率、计划时长、已完成的计划时长、全天事项、每日安排和分类分布。

规则：统计区间内有交集的日程按条目去重；跨天时长截取到区间；全天事项不换算为 24 小时；重叠日程分别累加。每日图显示每天涉及的事项数，因此跨天条目可能出现在多天。页面已标明计划时长不是实际计时。
